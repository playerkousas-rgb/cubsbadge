# 從 YMIS 匯出成員報告 → 批量開戶（領袖操作指引）

本文件教旅團領袖如何在香港童軍總會 **青少年成員資訊系統 (YMIS)** 匯出「指定欄位與次序」的自訂報表，
再於 **幼童軍進度追蹤平台（CubsBadge）** 一次過為全團幼童軍成員批量開戶。

> APP 內同樣有這份教學：登入 → 👥 用戶管理 → **📥 批量開戶** →「📘 如何在 YMIS 匯出指定格式報告？」

---

## 📌 一、從 YMIS 匯出指定格式報告

### 步驟一：搜尋與篩選旅團成員

1. 登入 [青少年成員資訊系統](https://ymis.scout.org.hk/#/private/MemberSearch)。
2. 點選頂部選單的 **「功能」** → **「搜尋成員紀錄」**。
3. 展開 **「成員紀錄」** 區塊：
   - 選擇所屬 **「地域」** 及 **「童軍區」**。
   - 在 **「童軍旅」** 輸入旅團代號（例如：`82`）。
4. 點擊 **「搜尋」** 按鈕。
5. 在下方成員列表中，手動勾選欲匯出的成員，或直接勾選列表最上方的 **「全選」**。

### 步驟二：進入「編製報告」與設定自訂格式

1. 確認成員勾選完畢後，點擊搜尋結果上方的 **「編製報告」** 按鈕。
2. 在彈出的設定視窗中：
   - **報告種類**：下拉選單切換為 **「自訂報表」**。
   - **排版設定**：上方的「排列」與「第二排列」可略過不變。

### 步驟三：設定欄位與強制鎖定次序（最關鍵！）

必須**嚴格依序**把以下三個欄位由左側加入右側的「已選擇之項目」：

| 次序 | YMIS 欄位 | 對應平台欄位 |
|---|---|---|
| 第一欄 | **童軍成員編號** | `ymis` |
| 第二欄 | **中文姓名** | `name` |
| 第三欄 | **電郵地址** | `email` |

> 💡 **注意事項**
> - 欄位的先後順序**完全取決於加入右側的先後順序**。
> - 右側每個欄位後方的寬度百分比可維持預設值（例如 `100%`）。

### 步驟四：產出與下載報表

1. 確認右側欄位順序為：**童軍成員編號 → 中文姓名 → 電郵地址**。
2. 點擊視窗右下方的 **「確定」**。
3. 系統會自動產生並下載 PDF 報告。

## 🔐 二、PDF 有密碼保護怎麼辦？

YMIS 匯出的 PDF 通常帶有密碼／加密，直接解析會讀不到內容。平台提供兩條路：

### 方案一（推薦）：APP 內建自動解鎖

CubsBadge 的「📥 批量開戶」對話框有 **「PDF 密碼（如有）」** 欄位：

1. 在該欄輸入 YMIS 給你的密碼（例如 `M28858467`）。
2. 按 **「📄 上載 YMIS PDF 報表」** 選擇檔案。
3. 前端使用 `pdf.js`（`getDocument({ data, password })`）在**瀏覽器內**解密與讀取；
   PDF **不會上傳到任何伺服器**，密碼亦不會被儲存。
4. 若沒有預先輸入密碼而 PDF 又加密，系統會即時彈出視窗要求輸入；密碼錯誤會提示重輸。

> 後端如需自行處理，可用 Python `pypdf` / `PyPDF2` / `pdfplumber` 的 `decrypt(password)`；
> 本平台為純前端靜態站，因此採用 `pdf.js` 方案，資料不出瀏覽器。

### 方案二：手動去除密碼後再上傳

1. 用 **Google Chrome** 或 **Edge** 開啟 PDF（輸入一次密碼解鎖）。
2. 點右上角 **「列印」**。
3. 列印目的地選擇 **「另存為 PDF (Save as PDF)」**。
4. 新儲存的 PDF 沒有密碼鎖，可直接上載。

### 方案三：複製文字貼上

若 PDF 是掃描圖或仍讀不到，可在 PDF 內選取表格文字複製，貼到對話框的
**「讀不到 PDF？可把報表文字複製貼上」** 文字框，按 **「🔍 解析貼上的文字」**。
每行格式：`童軍成員編號 中文姓名 電郵地址`（以空白、TAB 或逗號分隔皆可）。

## 🚀 三、在 APP 完成批量開戶

1. 以領袖／幼童軍團長／旅長／管理員身分登入 → **👥 用戶管理** → **📥 批量開戶**。
2. （如有）輸入 PDF 密碼 → **📄 上載 YMIS PDF 報表**。
3. 系統顯示 **匯入預覽**（可即場修改）：

   | 欄 | 說明 |
   |---|---|
   | 匯入 | 勾選才會開戶；已存在的 YMIS 預設不勾 |
   | YMIS | 由「童軍成員編號」讀入，須為 10 位數字（可按「🔢 全部補零至10位」） |
   | 姓名 | 由「中文姓名」讀入 |
   | 聯絡電郵 | 由「電郵地址」讀入 |
   | 狀態 | ✅ 可匯入／⚠️ 編號非10位／⚠️ 缺姓名／ℹ️ 缺電郵／⏭️ 已存在 |

4. 設定：
   - **預設小隊**（可留空，之後在用戶管理逐個調整）
   - **預設角色**（一般為幼童軍成員 `member`；幼童軍團長＝`branch_leader`、旅長＝`group_leader`）
   - **初始密碼**：
     - 留空 → 只把成員加入名單（`addMember`，不能登入，日後可讓領袖補開帳號）。
     - 有填 → 直接開立可登入帳號（`addUser`，密碼以 SHA-256 雜湊儲存，首次登入強制更改）。
5. 按 **「🚀 確認批量開戶」**，完成後會顯示「成功 X 筆，略過 Y 筆」。

> 幼童軍版注意：開戶時 `branch` 一律寫入 `cub`（幼童軍支部標記），小隊存於 `squad` 欄，
> 因此 app 後端的支部過濾（isCubBranch）會正確顯示新開戶成員。

### 報表實際版面（已對應）

YMIS 自訂報表輸出大致如下（每頁重複）：

```
                    香港童軍總會
            Scout Association of Hong Kong
                82nd Hong Kong Group
┌───────────────┬──────────────────┬───────────────────────┐
│ 童軍成員編號   │ 中文姓名          │ 電郵地址               │
│ Scout ID      │ Name in Chinese  │ Email                 │
├───────────────┼──────────────────┼───────────────────────┤
│ 2019051156    │ 陳大文            │ a.chan@example.com    │
│ 2019259338 *  │ 劉子彤            │ e.lau@example.com     │
│ 2019266200    │ 黎子柏            │ （空白）               │
└───────────────┴──────────────────┴───────────────────────┘
                                          第 1 頁，共 3 頁
```

解析器已針對這個版面處理以下情況：

| 情況 | 處理 |
|---|---|
| 欄名為**中英雙行**（童軍成員編號 / Scout ID …） | 兩行都會被視為表頭略過 |
| 抬頭「香港童軍總會 / Scout Association of Hong Kong / 82nd Hong Kong Group」 | 略過 |
| 成員編號帶 **`*`** 標記（如 `2019259338 *`） | 只取 10 位數字，`*` 不會混入姓名 |
| **電郵留空** | 照樣匯入，狀態顯示「ℹ️ 缺電郵」 |
| **多頁報表**（人多的旅團） | 逐頁讀取後合併；每頁重複的抬頭／欄名／頁碼自動略過，重複編號只取一次 |
| 頁尾「第 1 頁，共 3 頁 / Page 1 of 3」、列印時間戳 | 略過（只有數字、無姓名無電郵的行不會被當成成員） |
| 長電郵被 PDF 換行拆到下一行 | 自動補回上一位成員 |
| 中文姓名被 pdf.js 逐字拆開 | 依字距自動合併 |

### 加密相容性（已實測）

以同一份 3 頁、12 人的中文報表分別加密後測試，全部可用密碼正常讀取：

| 加密方式 | 無密碼開啟 | 輸入正確密碼 |
|---|---|---|
| RC4-128 | ❌ 要求密碼 | ✅ 3 頁 12 人全數讀出 |
| AES-128 | ❌ 要求密碼 | ✅ 3 頁 12 人全數讀出 |
| AES-256 | ❌ 要求密碼 | ✅ 3 頁 12 人全數讀出 |

> 若 PDF 只有「擁有者密碼」（限制列印／複製，開啟不需密碼），毋須輸入密碼即可直接讀取。

### 解析規則（技術說明）

解析器 [`assets/ymis-parse.js`](../assets/ymis-parse.js)：

- 以 pdf.js 的文字座標 `(x, y)` 還原表格列與欄，字距小於 8pt 的文字會合併為同一儲存格（避免中文姓名被拆開）。
- 每列依序抽取：**電郵**（正則）→ **6–12 位連續數字**作為童軍成員編號 → 餘下文字作為姓名。
  因此即使欄位次序有小差異或多了欄位，仍能正確對應。
- 自動略過抬頭／欄名／頁碼行（中英文皆可：「童軍成員編號」「Scout ID」「Name in Chinese」「香港童軍總會」「82nd Hong Kong Group」「第 1 頁，共 3 頁」「Page 1 of 3」、日期時間戳等）。
- 多頁：`parsePages()` 逐頁還原後合併，重複的成員編號只取第一筆，`skipped` 會標示頁碼。
- 只有數字、既無姓名亦無電郵的行（頁尾流水號）不會被當成成員。

## ⚠️ 常見問題

| 問題 | 處理 |
|---|---|
| 顯示「無法載入 PDF 解析元件」 | pdf.js 由 CDN 載入，需連網；或改用「貼上文字」／先另存無密碼 PDF |
| 讀不到成員 | 檢查報表欄位次序是否 童軍成員編號 → 中文姓名 → 電郵地址；或報表為掃描圖（無文字層） |
| 人多、報表有多頁 | 全部頁數會自動一次讀完，讀取時會顯示「正在讀取第 X／Y 頁」 |
| 匯入人數比報表少 | 多數是重複編號或該成員已在名單內（狀態顯示「⏭️ 已存在」） |
| 狀態顯示「編號非10位」 | 直接在預覽表格修改，或按「🔢 全部補零至10位」 |
| 狀態顯示「已存在」 | 該 YMIS 已在名單內，系統不會覆蓋既有資料 |
| 開戶後成員登入失敗 | 確認當時有填「初始密碼」；否則只是加入名單，需再開帳號或由領袖補開 |
