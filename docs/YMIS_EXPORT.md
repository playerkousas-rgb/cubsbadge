# 從 YMIS 匯出成員報告 → 批量開戶（幼童軍領袖操作指引）

本文件教領袖如何在香港童軍總會 **青少年成員資訊系統 (YMIS)** 匯出「指定欄位與次序」的自訂報表，
再於 **幼童軍進度追蹤平台（CubBadge）** 一次過為全團成員批量開戶。

> APP 內同樣有這份教學：登入 → 👥 用戶管理 → **📥 批量開戶** →「📘 如何在 YMIS 匯出指定格式報告？」
> 或 ❓ 教學 → 領袖教學 → 「📥 批量開戶（YMIS 報表匯入）」。
>
> ⚠️ 本文件所有編號、姓名、電郵均為示範用假資料（例如 `1234560001` / `陳大文` / `chan@example.org`），
> 不含任何真實成員資料。真實名單只會在你自己的瀏覽器內解析，再寫入你旅團自己的 Google Sheet。

---

## 📌 一、從 YMIS 匯出指定格式報告

### 步驟一：搜尋與篩選旅團成員

1. 登入 [青少年成員資訊系統](https://ymis.scout.org.hk/#/private/MemberSearch)。
2. 點選頂部選單的 **「功能」** → **「搜尋成員紀錄」**。
3. 展開 **「成員紀錄」** 區塊：
   - 選擇所屬 **「地域」** 及 **「童軍區」**。
   - 在 **「童軍旅」** 輸入你的旅團代號。
   - 支部可選 **「幼童軍團」**，只匯出幼童軍成員。
4. 點擊 **「搜尋」** 按鈕。
5. 在下方成員列表中，手動勾選欲匯出的成員，或直接勾選列表最上方的 **「全選」**。

### 步驟二：進入「編製報告」與設定自訂格式

1. 確認成員勾選完畢後，點擊搜尋結果上方的 **「編製報告」** 按鈕。
2. 在彈出的設定視窗中：
   - **報告種類**：下拉選單切換為 **「自訂報表」**。
   - **排版設定**：上方的「排列」與「第二排列」可略過不變。

### 步驟三：設定欄位與強制鎖定次序（最關鍵！）

必須**嚴格依序**把以下三個欄位由左側加入右側的「已選擇之項目」：

| 次序 | YMIS 欄位 | 對應平台欄位 |
|---|---|---|
| 第一欄 | **童軍成員編號** | `ymis` |
| 第二欄 | **中文姓名** | `name` |
| 第三欄 | **電郵地址** | `email` |

> 💡 **注意事項**
> - 欄位的先後順序**完全取決於加入右側的先後順序**。
> - 右側每個欄位後方的寬度百分比可維持預設值（例如 `100%`）。

### 步驟四：產出與下載報表

1. 確認右側欄位順序為：**童軍成員編號 → 中文姓名 → 電郵地址**。
2. 點擊視窗右下方的 **「確定」**。
3. 系統會自動產生並下載 PDF 報告。

## 🔐 二、PDF 有密碼保護怎麼辦？

YMIS 匯出的 PDF 通常帶有密碼／加密，直接解析會讀不到內容。平台提供三條路：

### 方案一（推薦）：APP 內建自動解鎖

CubBadge 的「📥 批量開戶」對話框有 **「PDF 密碼（如有）」** 欄位：

1. 在該欄輸入 YMIS 給你的密碼。
2. 按 **「📄 上載 YMIS PDF 報表」** 選擇檔案。
3. 前端使用 `pdf.js`（`getDocument({ data, password })`）在**瀏覽器內**解密與讀取；
   PDF **不會上傳到任何伺服器**，密碼亦不會被儲存。
4. 若沒有預先輸入密碼而 PDF 又加密，系統會即時彈出視窗要求輸入；密碼錯誤會提示重輸。

### 方案二：手動去除密碼後再上傳

1. 用 **Google Chrome** 或 **Edge** 開啟 PDF（輸入一次密碼解鎖）。
2. 點右上角 **「列印」**。
3. 列印目的地選擇 **「另存為 PDF (Save as PDF)」**。
4. 新儲存的 PDF 沒有密碼鎖，可直接上載。

### 方案三：複製文字貼上

若 PDF 是掃描圖或仍讀不到，可在 PDF 內選取表格文字複製，貼到對話框的
**「讀不到 PDF？可把報表文字複製貼上」** 文字框，按 **「🔍 解析貼上的文字」**。
每行格式：`童軍成員編號 中文姓名 電郵地址`（以空白、TAB 或逗號分隔皆可），例如：

```
1234560001  陳大文  chan@example.org
1234560002  黃小英  wong@example.org
```

## 📥 三、在 APP 內完成批量開戶

1. 領袖登入 → **👥 用戶管理** → **📥 批量開戶**。
2. 上載 PDF（或貼上文字）→ 系統顯示 **匯入預覽** 表格：
   - 每列可即場修改 **YMIS / 姓名 / 電郵**。
   - 已在名單內的成員會標示「⚠️ 已存在」並自動取消勾選（不會覆蓋）。
   - 編號不足 10 位可按 **「🔢 編號補足10位」** 一鍵補零。
3. 設定套用到所有選取成員的預設值：
   - **預設小隊**（例如 紅隊，可留空後續再改）。
   - **預設角色**：團員 / 支部領袖 / 團長 / 管理員。
   - **初始密碼**：
     - 留空 → 只加入 **純成員**（不可登入，進度由領袖記錄）。
     - 有填 → 開立 **可登入帳號**，首次登入強制改密碼。
4. 按 **「🚀 確認批量開戶」**，畫面會逐筆顯示成功／略過／失敗。

> 建議先以 2–3 位成員試做一次，確認無誤再匯入全團。

## 🛠️ 四、解析邏輯與測試

- 解析程式：[`assets/ymis-parse.js`](../assets/ymis-parse.js)（純前端，亦可在 Node 引用）。
- 單元測試：`node test/ymis_parse.test.js`（測試資料全部為假資料）。
- 解析器會自動略過報表抬頭、欄位標題、頁碼、列印日期等非資料行，
  並處理 PDF 把中文姓名拆成多個字元、長電郵折行等情況。

## ❓ 常見問題

| 問題 | 解決 |
|---|---|
| 讀不到任何成員 | 檢查報表欄位次序是否為「童軍成員編號 → 中文姓名 → 電郵地址」；或改用「貼上文字」。 |
| 編號少於 10 位 | 按「🔢 編號補足10位」補零，或在預覽中手動修正。 |
| 顯示「⚠️ 已存在」 | 該 YMIS 已在名單中，系統不會覆蓋；如需修改請用用戶管理逐個編輯。 |
| DEMO／試用模式無法開戶 | 批量開戶只在登入正式旅團後可用。 |
