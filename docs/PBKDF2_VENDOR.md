# PBKDF2 implementation provenance

`apps-script/Code.gs` embeds the PBKDF2/HMAC/SHA-256 implementation from
[@noble/hashes 1.8.0](https://github.com/paulmillr/noble-hashes/tree/1.8.0),
Copyright 2022 Paul Miller, MIT license. The complete license is embedded in
`Code.gs` beside the bundle. It does not use the library's random generator:
salts continue to be generated by the existing Apps Script UUID mechanism.

The build entry is `scripts/crypto-entry.cjs`. To reproduce the bundle, install
`@noble/hashes@1.8.0` and `esbuild@0.25.12` in an isolated temporary directory,
copy the entry there, then run esbuild with `--bundle --platform=neutral
--format=iife --global-name=CubPbkdf2 --minify`. The application has no runtime
npm dependency. `test/auth-hardening.test.mjs` checks the generated output
against Node crypto, including non-ASCII and long passwords.
