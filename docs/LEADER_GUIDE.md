## 帳號與權限重點

1. **旅長全旅只可有一位（硬鎖）**：後端 `getActiveGroupLeader()` 偵測現任在職旅長；任何新增（`addUser`）、批量開戶（`bulkAddUsers`）或改角色把某人升為旅長時，若全旅已有活躍旅長即拒絕，並顯示現任姓名（例：「旅長只能有一位，全旅已有現任旅長（陳大文）。如需更換，請先將現任旅長轉為其他角色。」）。換任流程：先將現任旅長降職／轉為幼童軍領袖／停用，即可升任新旅長。申請表不可直接申請旅長，即使竄改資料，審批時一律以 member 開戶。
2. **領袖免 YMIS、用電郵登入**：領袖申請／開戶不需 YMIS，後端自動編配內部序號 `L0001、L0002…`（不外洩、不當 YMIS 顯示）；領袖一律以電郵＋密碼登入（舊有 10 位 YMIS 領袖仍同時支援電郵與 YMIS 登入）。用戶管理、操作紀錄與審批彈窗會隱藏內部 `(Lxxxx)` 編號。
3. **初始密碼預設 1234 ＋ 首次登入強制改密**：申請批核後臨時密碼一律為 `1234`；首次登入即彈出「🔑 更改密碼」視窗（不可跳過），需設定 **4-8 位**新私人密碼後才可使用。
4. **權限收緊**：幼童軍領袖只能開立／管理 member（與自身同層或更高層角色一律不可越權建立）。

## 主要功能

- **中英文一鍵切換**：右上角 🌐 English / 中文，純介面翻譯層，項目 ID 及後端紀錄完全不變，後端仍用中文正名寫入，適合英語旅團。
- **保留帳號隱藏（v5.9）**：保留帳號只由 APP ADMIN 管理 —— `Code.gs` 只有帳號名，**GS 完全冇密碼**（密碼只存在 APP 層，APP 登入時喺 server 端比對）。任何人都唔可以喺 leaf 用密碼登入保留帳號（本地嘗試一律回「找不到此帳號」）。帳戶不寫入 Users 表、不在用戶管理／成員名單／操作紀錄出現，SHEET 登入紀錄（Tokens 表）亦零痕跡。防護保留：不能被停用／重設密碼／改角色／申請／批量開戶佔用。
- **幼童軍專用邏輯**：會員章→幼童軍體驗章→幼童軍歷奇章→幼童軍高級歷奇章→金紫荊獎章（2026年第十版）。全部進度由領袖填寫，家長/成員只看。進度申請預設關閉（allow_member_requests=false），活動履歷申報恆常開放（家長=成員帳號填寫，領袖審批）。
- **活動履歷「家長/成員申報 → 領袖審批」v5.2**：家長／成員可為自己申報服務／活動／訓練班紀錄；批准後才寫入活動履歷；已批准要改，由家長/成員再提交修改申報，經領袖重批後以同一 record_id 更新（只有履歷可自行申報修改；進度獎章及其他獎章批准後只有領袖可改）。
- **批量開戶**：上載 YMIS「自訂報表」PDF（支援密碼解鎖）自動讀出 YMIS／姓名／電郵，預覽後一鍵開戶；亦支援 Excel/CSV/JSON。
- **全團總覽**：卡片一眼睇會員章✓、百分比，表格矩陣最多30欄防卡死，按段章篩選，支援考驗營批量一鍵幫全團剔。
- **表格列印**：新制金紫荊資料核對清單（非官方表格），以及只供已核實過渡個案的舊制 PT/67、PT/68、24頁紀錄冊填寫核對；新制指定表格編號及欄位以總會最新公布為準。
- **主系統 Portal / iframe 接入**（⚠️ 暫停對外推廣 2026-10，程式碼保留照常運作）：?u=0082&role=&ymis=&from=portal&embed=1 自動帶入身份，免密碼。
- **離線暫存**：所有勾選先存瀏覽器，底部顯示未保存數量，按「確認寫入」才批量寫入雲端，寫入時有進度提示，失敗保留可重試。
- **診斷修復**：/api/health?troopId=0082 可檢查後端是否指向空表、缺少工作表；Apps Script 內執行 diagnoseSheets() / repairSheets() / getSpreadsheetInfo()。

## 功能詳解

### 我的進度

- 選任何幼童軍看紀錄，直接勾選+日期，離線暫存確認寫入，級聯自動完成（子項全完成→父項自動完成）。
- 成員（家長/幼童軍）不可勾選，僅查看。

### 全團總覽

- 卡片一眼睇邊個已完成會員章（會員章✓標籤）及各獎章百分比。
- 表格矩陣最多30欄，超過30欄提示分段章篩選，避免卡死（v5.1 修復）。
- 🚀考驗營批量完成：選成員+選項目+日期，一鍵幫全團剔，先暫存瀏覽器再批量寫入。
- 子切換：按成員總覽 / 按項目統計（百分比+人數）。

### 審批中心（合併版）

- 🏅獎章審批（進度申請，幼童軍預設無，因全部由領袖填寫）
- 📅履歷申報（家長/成員自行申報的服務／活動／訓練班紀錄，v5.2 新增，恆常開放）
- 👤用戶審批（新帳號註冊申請）
- 批量批准選中，批准後自動寫入進度或活動履歷，全部寫入操作紀錄。

### 活動履歷（服務／活動／訓練班紀錄）- 家長填領袖批

- 在「📅 活動履歷」頁先選成員，即可看到該成員的全部活動履歷，分為 🤝 服務紀錄、🏕️ 活動紀錄、🎓 訓練班紀錄 三類，並統計服務總時數。
- 「➕ 新增紀錄」可選類型：服務紀錄記錄服務時數；訓練班紀錄只須填名稱、日期及證書編號，身份一律為「學員」；活動紀錄記錄崗位／身份。
- 勾選「📥 批量」可一次將同一活動套用到多個成員（電腦 Ctrl 多選，手機逐點多選）。
- 領袖可隨時 ✏️ 編輯或 🗑️ 刪除任何紀錄；刪除不能復原。
- **家長/成員申報**：家長/成員帳號可在同一頁按「📝 申報紀錄」自行申報，提交後由領袖審批，批准後才寫入。已批准如需修改，家長/成員按✏️提交修改申報，經領袖重批後以同一 record_id 更新，批准前可取消。其他（進度、活動徽章）批准後只有領袖可改。
- ⚠️ 若旅團後端未升級，頁面會顯示升級提示：Apps Script 貼上最新 Code.gs（GS 2026.10.25）→ 管理部署 → 新版本部署（URL 不變）。只有新建或確實缺少工作表的 Sheet 才需執行 initializeSheets() 補建；已有正常 Sheet 今次毋須重跑。

### 用戶管理（角色及權限）

- 角色：幼童軍成員 member（家長/成員帳號，只看）、幼童軍領袖（團長／副團長） branch_leader、旅長 group_leader、管理員 admin、保留帳號 super_admin（隱藏，APP ADMIN 專用）。
- 權限：領袖默認全部(*)，成員無，可按個別成員設定可考核範圍（領袖之間）。
- 📥 批量開戶：①上載 YMIS「自訂報表」PDF（自動讀編號/姓名/電郵，可預覽修改）②下載 Excel/CSV範本→填寫→上傳 ③貼上 JSON；一次過幫全團開戶。
- ➕ 單個新增成員/帳號：有密碼=可登入帳號（首次登入強制改密），無密碼=純成員（會建立 Users 紀錄，之後可隨時「開通帳號（設定密碼）」）。

- 🔄 重新啟用（v5.3.2 新增）：已停用帳號可一鍵重新啟用，密碼重設為 1234（首次登入強制改密），並自動補回成員名單；清單頂部「顯示已停用」可展開已停用帳號。
- 🧢 小隊職務：用戶管理可將成員設為隊員（`member`）、隊長（`sixer`）或副隊長（`vice_captain`）；純成員（未開登入帳號）亦可設定。帳戶角色另可選幼童軍領袖（團長／副團長）等系統角色，兩者不可混用。
- 🗑️ 刪除成員（v5.3.2 新增）：純成員可直接移出成員名單；有帳號的成員刪除時會一併停用帳號（YMIS 不會被重用，需要時走「重新啟用」）。
- 🧾 操作紀錄、✅ 審批歷史：可搜尋。
- 🔒 系統設定：允許成員互相查看進度（鼓勵/私隱）、成員查看範圍（只看自己/全隊/全團等）、小隊完成率比較、允許成員提交進度完成申請（幼童軍預設關閉，全部由領袖填寫；活動履歷申報恆常開放不受此開關影響）。

### 系統修復紀錄

- **Fix POST load forwarding to Apps Script doGet**：前端所有 apiRequest 經 /api/proxy，後端 Registry 可信查找 GAS URL，安全拒絕任意 URL。load 動作前端發 POST，但 Apps Script doGet 實現，proxy 自動轉為 GET，避免「找不到SHEET」誤判及 CORS / Failed to fetch。
- **Fix Vercel API serverless function deployment**：vercel.json 加入 builds 和 routes，確保 data/**, assets/**, docs/**, apps-script/** 作為 @vercel/static，api/** 作為 @vercel/node，避免之前空 {"version":2} 導致 /api/troops 404，首頁 0082 無法選擇，立即 fallback 渲染（hard fallback 0082）。
- **Fix SyntaxError await in batchApprove breaking homepage JS**：batchApprove 必須為 async function，避免 await 在非 async 函數中導致整頁 JS 報錯卡死。
- **Fix 82/0082 normalization**：normalizeToPadded4 / normalizeStripped，0082 和 82 互通，proxy 返回 troubleshooting 提示，健康檢查 /api/health 檢查 normalization 是否工作。
- **Enhance diagnoseSheets to detect empty SHEET**：diagnoseSheets() 檢查必要工作表是否齊全，usersCount / membersCount 判斷是否為空表/被重置，提示檢查是否連錯試算表。
- **保留帳號隱藏（v5.7）**：SETUP 彈窗永不顯示帳號密碼（只顯示旅團要交俾 APP ADMIN 嘅 API Key）；Users 表、用戶管理、成員名單、操作紀錄都唔會出現該帳戶；保留帳號檢查、移除舊列、防護保留。

## 日常紀錄及金紫荊申請工作流程

1. 日常訓練：在「我的進度」逐項記錄完成日期；需要證明的項目可在備註中註明活動日期、地點或照片存放位置。APP 和 Google Sheet 就是正式的團內工作紀錄，無須再列印。
2. 活動履歷：家長/成員可在「活動履歷」申報服務/活動/訓練班，領袖審批後寫入，統計服務總時數，訓練班記錄證書編號。
3. 領袖在審批中心核對後確認，避免重覆抄寫紙本。
4. 準備金紫荊獎章時，才在「金紫荊申請」頁使用資料核對及官方紀錄冊填寫清單。
5. 新制只列印資料核對清單，並向所屬童軍區確認最新指定表格；沿用舊制的過渡個案才使用舊制 PT/67、PT/68 及紀錄冊。

> APP 已涵蓋會員章、幼童軍體驗章、幼童軍歷奇章、幼童軍高級歷奇章、金紫荊獎章及現行活動徽章目錄；舊 ID 紀錄另列且不計完成度。專業活動、安全規定、正式簽發與官方表格以香港童軍總會最新版本為準。
