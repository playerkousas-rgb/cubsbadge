# 👨‍💼 幼童軍領袖教學

> 全部由領袖負責，不需細緻權限

## 資料範圍
- 此部署只處理**幼童軍支部**的成員、進度和獎章；不要把其他支部的名單或紀錄匯入此 Google Sheet。
- 系統維護帳號不會出現在成員名單、全團總覽或用戶管理中。

## 功能
- 我的進度選任何幼童軍看紀錄
- 全團總覽一眼睇邊個已完成金紫荊、一眼睇活動徽章
- 批量剔：選成員+選項目+日期一鍵剔
- 待批批量批准
- 用戶管理改角色
- 私隱開關：允許成員互看進度

## 專科徽章
- 活動徽章一級制及三級制，全部由領袖評核
- 金紫荊需至少1個指定活動徽章（單車/游泳/探險等）

## 電子紀錄冊工作流程
1. 在「我的進度」逐項記錄完成日期；需要證明的項目可在申請／備註中註明活動日期、地點或照片存放位置。
2. 領袖在審批中心核對後確認，避免重覆抄寫紙本考驗紀錄。
3. 在「表格列印」選擇「完整幼童軍電子紀錄冊」，列印或存 PDF 作團內檔案及家長溝通。
4. 金紫荊獎章使用系統產生的支援摘要整理資料，並配合總會最新 PT/67、PT/68 官方表格及程序遞交。

> 電子紀錄冊已涵蓋會員章、幼童軍獎章、歷奇章、高級歷奇章、金紫荊獎章及活動徽章名錄；專業活動、安全規定、正式簽發與官方表格以香港童軍總會最新版本為準。
