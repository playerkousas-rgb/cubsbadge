# 👨‍💼 幼童軍領袖教學

> 全部由領袖負責，不需細緻權限

## 資料範圍
- 此部署只處理**幼童軍支部**的成員、進度和獎章；不要把其他支部的名單或紀錄匯入此 Google Sheet。
- 系統維護帳號不會出現在成員名單、全團總覽或用戶管理中。

## 功能
- 我的進度選任何幼童軍看紀錄
- 全團總覽一眼睇邊個已完成金紫荊、一眼睇活動徽章
- 批量剔：選成員+選項目+日期一鍵剔
- 待批批量批准
- 📅 活動履歷：為成員補登／編輯／刪除**服務紀錄**（含時數統計）、**活動紀錄**、**訓練班紀錄**（含證書編號）；支援「同一活動批量套用到多個成員」（例如全團露營一次過補登）
- 用戶管理改角色
- 私隱開關：允許成員互看進度

## 帳號管理（全前端控制）
- 📥 批量開戶：下載 Excel／CSV 範本 → 填寫 → APP 內直接上傳（支援 .xlsx/.csv），一次過幫全團開戶；或貼 JSON 陣列（詳見 `docs/BULK_ONBOARD.md`）
- ➕ 新增成員/帳號：有密碼 = 可登入帳號（首次登入強制改密）；無密碼 = 純成員（唔使登入）
- 🔑 重設密碼：產生一次性密碼，成員首次登入自行設定新密碼
- 🗑️ 停用帳號：停用後無法登入，進度資料保留
- ✅ 審批歷史、🧾 操作紀錄：可搜尋的紀錄列表
- 全部管理動作在 APP 完成，唔使入 Google Sheet

## 專科徽章
- 活動徽章一級制及三級制，全部由領袖評核
- 金紫荊需至少1個指定活動徽章（單車/游泳/探險等）

## 📅 活動履歷（服務／活動／訓練班紀錄）
- 在「📅 活動履歷」頁先選成員，即可看到該成員的全部活動履歷，分為 🤝 服務紀錄、🏕️ 活動紀錄、🎓 訓練班紀錄 三類，並統計服務總時數。
- 「➕ 新增紀錄」可選類型（服務／活動／訓練班）：服務紀錄記錄服務時數；**訓練班紀錄**只須填訓練班名稱、日期及證書編號（如有），身份一律為「學員」；活動紀錄記錄崗位／身份。
- 勾選「📥 批量」可一次將同一活動套用到多個成員（電腦按住 Ctrl 多選，手機逐點多選）。
- 領袖可隨時 ✏️ 編輯或 🗑️ 刪除任何紀錄；刪除不能復原。
- 成員只能查看自己的紀錄（只讀）。
- ⚠️ 若旅團後端未升級，頁面會顯示升級提示：Apps Script 貼上最新 Code.gs → 執行 `initializeSheets()` 補建「活動履歷」工作表 → 管理部署 → 新版本部署（URL 不變）。

## 日常紀錄及金紫荊申請工作流程
1. 日常訓練：在「我的進度」逐項記錄完成日期；需要證明的項目可在申請／備註中註明活動日期、地點或照片存放位置。APP 和 Google Sheet 就是正式的團內工作紀錄，無須再列印或另存 PDF。
2. 領袖在審批中心核對後確認，避免重覆抄寫紙本考驗紀錄。
3. 準備金紫荊獎章時，才在「金紫荊申請」頁使用資料核對及官方紀錄冊填寫清單。
4. 將已核對資料填回香港童軍總會最新的官方金紫荊獎章考驗紀錄冊，並配合最新 PT/67、PT/68 官方表格及程序遞交。

> APP 已涵蓋會員章、幼童軍獎章、歷奇章、高級歷奇章、金紫荊獎章及活動徽章名錄。專業活動、安全規定、正式簽發與官方表格以香港童軍總會最新版本為準。

## 旅團證書
- 在「🏅 金紫荊申請」頁先選成員，再於「幼童軍旅團證書」選擇會員章、進度性徽章或活動徽章，即可列印旅團完成證書。
- 證書會顯示系統內該徽章的完成紀錄，簽發前仍由領袖按實際評核結果核對。
- 這是旅團內部完成證書；金紫荊獎章及任何總會正式證書一律依香港童軍總會的最新程序處理。
