# 👤 幼童軍成員／家長使用教學 (Member / Parent) v5.2

> 幼童軍年紀小，全部進度由領袖填寫，家長/成員只看（所謂家長=成員帳號）

## 登入後你會見到

- **📊 我的進度**：只顯示自己的完成度（會員章→金紫荊），綠色進度條=已完成，點擊獎章展開，右側ⓘ查看考驗說明。**不可直接勾選，進度由領袖負責更新**。進度申請（📝申請完成）預設關閉，全部由領袖填寫。
- **👥 全團總覽**：預設不顯示（私隱）。若團長開啟「允許成員互相查看進度」，可看到全團卡片及按項目統計，但不能編輯。
- **📅 活動履歷**：查看自己的服務／活動／訓練班紀錄（Service / Activity / Training）。可按「📝 申報紀錄」自行申報（家長=成員帳號，背後可能是家長在處理），需領袖審批後才寫入。已批准如需改，可再提交修改申報，經領袖重批後以同一紀錄更新。待批申報可自行取消。
- **✅ 審批中心**：查看自己的活動履歷申報是否已批，可取消待批。
- **🏅 金紫荊申請**：日常進度已直接在 APP 及 Google Sheet 保存，毋須再次列印。本頁只在準備金紫荊獎章開展、考驗及申請時使用，產生官方紀錄冊填寫核對清單。
- **📚 資料庫**：保護兒童 Safe from Harm、訓練綱要、森林故事、制服、儀式等官方連結。
- **🌐 中英切換**：右上角按「🌐 English / 中文」可全站轉英文，內容相通，後端紀錄相同，適合英語旅團。項目 ID 及後端紀錄完全不變，僅介面翻譯。

## 活動履歷申報（家長填領袖批）- v5.2 新增

與童軍支部一致：

1. 在「📅 活動履歷」按「📝 申報紀錄」
2. 選類型（服務／活動／訓練班）、日期、名稱（服務可填時數、訓練班可填證書編號，身份固定為學員）
3. 提交後進入「待領袖審批」，可在同一頁或「審批中心 → 履歷申報」看到，可自行取消
4. 領袖批准後才寫入活動履歷
5. 已批准的紀錄要改？按 ✏️ 提交「修改申報」，領袖重批後以同一紀錄更新（批了要改→再申報→領袖重批）

注意：進度性獎章（會員章至金紫荊）、其他獎章（活動徽章）批准後只有領袖可改；只有履歷可以自行申報修改。

## 為何看不到其他成員？

預設私隱，成員只看自己。團長可在用戶管理開啟「允許成員互相查看進度」（僅查看，不可編輯）及設定查看範圍（只看自己/全隊/全團等）。
