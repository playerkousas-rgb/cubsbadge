# YMIS 獎章匯出（試行）

領袖登入後，在「全團總覽」按「匯出 YMIS 獎章（試行）」。不需更新 Apps Script 或重新初始化試算表。

1. 選擇一款已正式獲頒的獎章。
2. 勾選成員，逐人填寫實際獲獎日期（沒有預設日期）。
3. 核對成員 YMIS 編號、獎章、日期及 YMIS 現有紀錄，勾選確認。
4. 下載 XLSX。
5. YMIS → 成員註冊 → 資料檔案上傳 → **新增支部獎章紀錄**，上傳並按系統指示確認。不要選完整青少年成員登記。

每次匯出一款獎章、多位成員；其他獎章另行匯出。未選成員不輸出。獎章與日期由領袖明確指定，不從考核完成度推斷，不會更改 CUBSBADGE 進度。選取狀態只在本次視窗內保留；關閉或重新整理後需重新輸入。

四欄（依使用者提供的 YMIS 範本）：

`Scout ID`, `Badge-Section`, `Badge-Badge`, `Badge-award date (YYYYMMDD)`

- Scout ID：10位數字，以文字儲存以保留前導零。
- 支部固定 `Cub Scout`。
- 獎章：`Membership Badge`、`Cub Scout Award`、`Cub Scout Adventure Award`、`Cub Scout Adventure Crest Award`、`The Golden Bauhinia Award`。
- 日期：`YYYYMMDD`。
- 不包含專章、活動章、舊箭章、考核細項或範本示例。

## 驗證界線

本地測試涵蓋欄名、映射、日期、編號、重複行及工作表資料。**尚無真實資料在 YMIS 驗證**，不保證其服務端接受；不是官方 API 串接，也不會自動得知上傳結果。匯出不等於匯入成功。沒有跨次匯出／YMIS 重複偵測，請自行核對並勿重複上傳。

首次使用建議先上傳一筆真實未登記紀錄，確認結果再批量使用。若出錯，請經 APP 回報功能提供錯誤文字或遮蓋個資的截圖、所選範本種類；不要提交含真實成員編號的完整檔案。下載檔案含個人識別資料，請妥善保管。
