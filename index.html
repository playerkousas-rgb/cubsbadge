📖 使用教學 - 幼童軍專用

1

選擇旅團

首頁點旅團卡片

2

登入

成員/家長：YMIS 10位 + 密碼；領袖：Email + 密碼。首次登入強制改密。

3

家長/成員：只看進度，可申報活動履歷

幼童軍年紀小，所有進度由領袖填寫，家長/成員帳號只能查看。但活動履歷（服務／活動／訓練班）可由家長/成員自行申報 → 領袖審批。

4

領袖：勾選+日期

領袖直接勾選，自動填今日日期，可手改。先暫存瀏覽器，底部確認寫入雲端。

5

其他功能

全團總覽批量、按項目統計、表格列印 PT/68 金紫荊、中英切換。

👥 角色功能

👤 家長/成員 member
  • 只能看自己進度（不可勾選）
  • 活動履歷可自行申報（服務/活動/訓練班）
  • 可取消待批申報
  • 已批紀錄可申請修改（需領袖重批）
👨‍💼 領袖 leader
  • 全部功能
  • 我的進度選任何成員
  • 全團總覽批量一鍵剔
  • 審批中心：用戶+活動履歷申報
  • 活動履歷可直接新增/編輯/刪除+批量
  • 用戶管理、批量開戶 YMIS PDF

🆕 帳戶申請／批量開戶

個人：登入頁按「申請成員帳戶」→ 領袖審批。
批量：用戶管理 → 批量開戶 → 上載 YMIS 自訂報表 PDF（自動讀編號/姓名/電郵）→ 預覽後開戶。

📥 批量開戶 - 全前端控制

方法一：YMIS 自訂報表匯入（推薦，最快）
上載由 YMIS 匯出的「自訂報表」PDF（可輸入 PDF 密碼），系統自動讀出 童軍成員編號 / 中文姓名 / 電郵地址，預覽確認後一次過開戶。PDF 只在你部手機／電腦內解析，不會上傳到任何伺服器。

📘 如何在 YMIS 匯出指定格式報告？（點擊展開）
登入 YMIS → 功能 → 搜尋成員紀錄 → 選地域／童軍區 → 輸入旅團代號 → 搜尋 → 勾選幼童軍成員 → 按「編製報告」→ 報告種類選「自訂報表」→ 依序加入：童軍成員編號 → 中文姓名 → 電郵地址 → 確定下載 PDF
讀不到 PDF？可把報表文字複製貼上（每行：編號 姓名 電郵）：
